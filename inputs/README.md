# Input privati

Depositare gli originali solo in `inputs/private/`: CV, esportazione LinkedIn, note sulle esperienze, prove dei risultati, foto e screenshot. Creare qui una copia del [questionario](../docs/content.md) come `inputs/private/content.md` e compilarla con fonti, stati e permessi. Questa cartella è esclusa integralmente da Git tramite [`.gitignore`](../.gitignore); non usarla per file destinati alla pubblicazione.

Non inserire materiali grezzi, credenziali o dati personali nei documenti tracciabili, nei commit, nei ticket o nelle bozze del sito. Prima di usare un contenuto, selezionarlo, verificarne diritti e autorizzazioni, rimuovere dati sensibili e identificatori non necessari, poi registrare l'approvazione. Copiare nel sito futuro soltanto la versione approvata e anonimizzata. Conservare l'originale in `inputs/private/`.

L'esclusione Git riduce il rischio di commit accidentali, ma non sostituisce il controllo dei contenuti prima della pubblicazione.
